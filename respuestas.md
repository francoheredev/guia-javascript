Ejercicio 30: Eventos en JavaScript
¿Qué es un evento en JavaScript?
Un evento es una acción o suceso que ocurre en el navegador, ya sea por una interacción del usuario (como hacer clic, mover el mouse o presionar una tecla) o por el propio sistema (como terminar de cargar una página). JavaScript los "escucha" para reaccionar ante ellos con código.

Análisis del código:

¿Qué elemento escucha el evento?
El elemento almacenado en la variable boton (que suele ser un elemento del DOM obtenido con getElementById).

¿Qué evento se está escuchando?
El evento "click", que se dispara cuando el usuario presiona y suelta el botón izquierdo del mouse sobre el elemento.

¿Qué acción se ejecuta?
Se ejecuta una función anónima que imprime el mensaje "El usuario hizo clic" en la consola del navegador.

¿Dónde podríamos aplicar esto en una página web o videojuego?

En una web: Para enviar un formulario de contacto, abrir un menú desplegable o cambiar el modo oscuro/claro de la página.

En un videojuego: Para que el personaje salte al presionar un botón, iniciar la partida desde el menú principal o interactuar con un objeto del mapa.
